# nogrod/xml-client-runtime

# Installation

## Download the Bundle

Require the bundle in your `composer.json` file:

``` bash
$ composer require nogrod/xml-client-runtime
```

This package supports `symfony/expression-language` `^5.0|^6.0|^7.0|^8.0`.
When using `symfony/expression-language` `^8.0`, Composer will require PHP `>=8.4` to satisfy Symfony 8 itself.
